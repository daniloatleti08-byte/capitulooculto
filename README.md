# O Capítulo Oculto — Página de Vendas

Página de vendas do guia devocional **"O Capítulo Oculto — Prosperidade"** da Casa de São Bento.

## Estrutura

```
index.html   → Página principal com todas as 13 seções
style.css    → Design system dark premium
script.js    → Animações e interações
```

## Deploy na Vercel

1. Crie um repositório no GitHub e faça push deste projeto
2. Acesse [vercel.com](https://vercel.com) e conecte o repositório
3. A Vercel detectará automaticamente que é um site estático
4. Clique em "Deploy"

## Configurações pendentes

Antes de publicar, substitua nos arquivos:

- **Meta Pixel**: No `index.html`, descomente o bloco do pixel e troque `SEU_PIXEL_ID_AQUI` pelo seu ID
- **Link de checkout**: Substitua `#LINK_CHECKOUT` pelo link da Cakto em todos os botões CTA
- **Vídeo VSL**: Substitua `SEU_ID_DO_VIDEO` pelo ID do YouTube ou plataforma de vídeo
- **Dados legais**: Atualize CNPJ, razão social e e-mail de suporte no rodapé
